# Independent DOCX import fixtures

These pre-existing files come from Mammoth.js tag 1.12.3, under its BSD-2-Clause license (LICENSE).
They were not generated by the Office exporter. Their package metadata names Microsoft Office Word;
this does not establish a live Word application test.

Source: https://github.com/mwilliamson/mammoth.js/tree/1.12.3/test/test-data

- simple-list.docx: Apple and Banana in a bullet list.
- tables.docx: Above, a 2x2 table (Top left/Top right/Bottom left/Bottom right), Below.
- tiny-picture.docx: an embedded PNG.

Heading/inline-format/link export is separately checked against literal standard XML semantics;
these three files do not cover every Word formatting feature.

The included upstream license terms are unchanged; trailing line whitespace is normalized.
